# 月と手帳 v0.2 作業報告

作業日：2026-09-30。GitHub main `1c96f43` から取得し、ローカルの `feat/v0.2-master-ui` で作業しました。commit / push / 本番デプロイは行っていません。

## 実装したこと

- MASTER UIの構成に沿って、湖畔のヒーロー、4つの入口、新着記事、手動推薦、手帳のある室内、ブランドの4つの価値、夜のCTA、フッターへTOPを再構成。
- CTAから `/oracle/` へ直接移動。同一デザインの裏面5枚を3枚＋2枚に配置。番号・章・テーマ選択なし。
- 36枚を毎回シャッフルし、選んだ位置の1枚を表示。連打防止、控えめな浮き・フリップ、動きを減らす設定、結果へのフォーカス移動、再ドローを実装。
- 結果は大きな絵と名前・keyword、短い前向きなことば、メッセージ、手帳への問い。テーマ別の4分割はありません。
- 取得したmainは12枚だったため、既存のID・本文を保持して24枚を追加。正式4章に各9枚を収録。章は内部データ。
- Content Collectionsの既存5記事を更新し、オラクルの読み方1本を追加。全6本。記事の目次・関連記事・日付・著者・出典欄を整備。
- `/reading/` と `/about/` を追加。将来のSNSリンクをmedia.tsに用意し、未設定のリンクは表示しません。

## 削除・整理

- テーマ選択、横方向にカードを送るUI、画面内の手帳入力フロー。
- カード一覧 `/oracle/cards/`、月情報の中間ページ `/moon/`。
- 未完成の月齢・確認中表示、古い月・手帳遷移用コンポーネントと旧スタイル。
- カード個別ページは既存URLを維持。旧月記事と削除ページは `public/_redirects` で301転送します。

## SEO

全ページにtitle・description・canonical・OGP・WebSite・Organization。記事にはBlogPosting、記事と階層ページには画面表示に一致するBreadcrumbListを生成。著者は実際のサイト名義「月と手帳」で、資格・実体験・レビューは追加していません。

サイトマップは46ページ。新着記事は公開日順、推薦枠はfeatured指定でアクセスランキングとは表示しません。記事slugの重複・固定URLとの衝突・関連記事の参照・日付の前後をビルドで検証します。

新月カレンダー・日時・星座は未確認のため掲載せず、記事内の内部TODOに留めました。titleでも未提供のカレンダーを約束していません。一次情報を掲載できるsources / firsthandNoteフィールドがあります。

## 画像と記事の運用

湖畔・手帳・人物のいるカード絵を新規生成しました。モック画像の切り出しは使用していません。記事のアイキャッチも共通画像を仮使用しています。36枚の絵はすべて共通の仮画像です。

- 共通パス：`src/data/media.ts`
- 個別カード：`public/images/oracle/[slug].webp` を配置して再ビルド。例：`yohaku.webp`。
- 画像比率：2:3、contain。未配置・読込エラー時は共通絵へフォールバック。
- 記事：`src/content/articles/` にMarkdown追加。テンプレートは [article-template.md](article-template.md)。
- 生成モード・使用プロンプト・保存先は [IMAGES.md](IMAGES.md)。
- 初期記事の日付は作業日を設定しています。実際の公開時に原稿・日付を確認してください。
